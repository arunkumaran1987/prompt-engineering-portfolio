# 💼 Arun's Prompt Engineering Project Portfolio

Welcome! This GitHub portfolio showcases my hands-on projects and experiments in **Prompt Engineering** and **Generative AI**, built on top of my 14+ years of experience as a Product Owner and Business Analyst.
---
## 📁 Project Structure

### 1. `prompt-library-product-management/`
**Description:** A categorized collection of prompt templates used in Agile/Product workflows.

**Includes:**
- User story generation
- Acceptance criteria drafting
- Sprint planning assistants
- Test case prompts
- Backlog grooming

👉 Ideal for Product Managers and BAs transitioning into AI-powered workflows.

---

### 2. `llm-requirements-analyzer/`
**Description:** An OpenAI-powered tool that extracts and analyzes requirements from uploaded BRDs/PRDs.

**Stack:** Streamlit + OpenAI GPT-4

**Features:**
- Upload PRD → get epics and user stories
- Suggest missing requirements
- Export in CSV or JIRA-importable format

### 3. `prompt-performance-tracker/`
**Description:** A tracker that tests, compares, and scores various prompts for performance and output consistency.

**Tools:** Google Sheets or Python + Pandas

**Includes:**
- Prompt structure variants (zero-shot, few-shot, role-based)
- Evaluation metrics (relevance, accuracy, hallucination rate)

---

### 4. `ai-assistant-for-pms/`
**Description:** A domain-specific chatbot for Product Managers.

**Built With:** GPT-4, LangChain (optional), Streamlit

**Capabilities:**
- Suggest product ideas
- Explain technical jargon
- Summarize stakeholder feedback
- Generate product requirement templates

---

### 5. `articles-and-use-cases/`

**Includes:**
- “How Prompt Engineering is Transforming Product Management”
- “Prompt Experiments: What Worked and What Didn’t”
- Use-case comparisons: Traditional vs AI-powered BA tasks
